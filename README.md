## Overview

githubchartsbadges is an all-in-one developer tool that transforms GitHub repository data into engaging visual badges and charts. Designed for seamless integration and scalability, it helps teams monitor, analyze, and showcase project metrics effortlessly.

**Why githubchartsbadges?**

This project aims to provide a robust platform for visualizing GitHub insights. The core features include:

- 🎨 **Colorful Badges:** Generate dynamic SVG badges reflecting repository stats like stars, issues, and forks.
- 📊 **Interactive Charts:** Create customizable, data-driven visualizations of commit trends, code churn, and more.
- 🚢 **Containerized Deployment:** Use Docker and Docker Compose for consistent, portable environments.
- 🔗 **GitHub API Integration:** Seamlessly fetch and process repository data for real-time insights.
- ⚙️ **Modular Architecture:** Easily extend and maintain with dedicated backend, frontend, chart, and badge modules.

## Getting Started

This project requires the following dependencies:

- **Programming Language:** Java
- **Package Manager:** Maven, Npm
- **Container Runtime:** Docker

### Installation

Build githubchartsbadges from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/Sorana09/githubchartsbadges
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd githubchartsbadges
    ```

3. **Install the dependencies:**

**Using [docker](https://www.docker.com/):**

```sh
❯ docker build -t Sorana09/githubchartsbadges .
```
**Using [maven](https://maven.apache.org/):**

```sh
❯ mvn install
```
**Using [npm](https://www.npmjs.com/):**

```sh
❯ npm install
```

### Usage

Run the project with:

**Using [docker](https://www.docker.com/):**

```sh
docker run -it {image_name}
```
**Using [maven](https://maven.apache.org/):**

```sh
mvn exec:java
```
**Using [npm](https://www.npmjs.com/):**

```sh
npm start
```
