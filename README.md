## Overview

githubchartsbadges is an open-source developer tool designed to convert GitHub repository data into visually appealing badges and charts, enabling real-time insights and enhanced project monitoring. Built with a modular architecture, it seamlessly integrates backend services, visualization libraries, and external APIs to deliver dynamic, customizable visual representations of project statistics.

**Why githubchartsbadges?**

This project simplifies the process of monitoring GitHub repositories by providing automated, real-time visual insights. The core features include:

- 🎨 **Colorful Badges:** Generate SVG badges for metrics like stars, issues, and forks, perfect for dashboards and documentation.
- 📊 **Interactive Charts:** Create customizable charts such as commit history, contribution breakdowns, and code churn.
- 🚀 **Scalable Deployment:** Use Docker Compose to deploy and scale services effortlessly across environments.
- 🔗 **API Integration:** REST endpoints facilitate easy integration with existing workflows and dashboards.
- 🌙 **Theme Support:** Switch between light and dark modes for visual consistency.
- ⚙️ **Modular Architecture:** Leverage dedicated modules for badges, charts, and GitHub API interactions for flexible development and maintenance.
